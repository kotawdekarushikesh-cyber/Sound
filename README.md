# Charger Sounds

Plays your own sound when the charger is connected, disconnected, and when the battery reaches 100%.

## Get the APK
1. Create a new GitHub repository and upload everything in this folder (including `.github`).
2. Open the **Actions** tab -> **Build APK** -> wait for the green check.
3. Open the finished run -> **Artifacts** -> download `ChargerSounds-apk` (a zip containing `app-debug.apk`).
4. Unzip, open the APK on your Android phone, allow "install unknown apps" when asked.

## Use
Open the app, pick a sound for each event (system sounds or any audio file), tap Test.
Tap "Allow background running" so Android doesn't stop the service.
